## Step 1: assign a rank to every input word

Before doing anything else, rank the input words by frequency:

1. Sort all input words by frequency, highest first. If two words have the same frequency, keep them in the
   order they appear in the input.
2. The most frequent word gets rank 1651, the next gets 1651 + 1, and so on, one number per
   input word.
3. **Every input word gets a rank, including words you later skip in step 2.** Skipped words still use up
   their number, so the ranks of the other words don't shift.

## Step 2: decide what to output for each input word

1. **Skip words that are not useful vocabulary.** Output nothing for:
   - proper nouns: names of people, places, brands
   - fillers and noises, e.g. "eh", "ah", "mmm", "jaja"
   - tokens that are not Spanish, abbreviations, or stray single letters (real words such as "a", "y", "o" and "e" are kept)
   - profanity and slurs
2. **Use the dictionary form (lemma).** The subtitle list contains inflected forms, so convert them:
   - verbs → infinitive ("tengo", "tiene", "tuvo" → "tener")
   - nouns → singular ("casas" → "casa")
   - adjectives → masculine singular ("buenas" → "bueno")
   - pronouns, articles, determiners, prepositions and contractions stay as they are ("la", "los", "me", "del", "al")
3. **One entry per lemma.** If several input words share a lemma, output it once. Its rank is the lowest
   (smallest) rank among those input words.
4. **Words with more than one part of speech.** If an input word is common in two different parts of speech,
   output one entry for each (maximum two per input word), both with that input word's rank. An example is
   "como": the conjunction/adverb "como", plus the verb "comer". Only do this when both uses are genuinely common.

## Output format

Return **only** a JSON array. Do not wrap it in markdown code fences, and do not add comments or explanations.
Each element must have exactly these fields:

| field          | type                  | rules |
|----------------|-----------------------|-------|
| `word`         | string                | The lemma, in lowercase unless it is always capitalised. Correct accents (é, ñ, ü...). Nouns have no article ("casa", not "la casa"). |
| `translation`  | string                | The most common English meaning(s): up to 3, separated by ", ". Verbs start with "to " ("to have"). No explanations in brackets. |
| `partOfSpeech` | string                | One of: `NOUN`, `VERB`, `ADJECTIVE`, `ADVERB`, `PRONOUN`, `PREPOSITION`, `CONJUNCTION`, `INTERJECTION`, `DETERMINER`, `NUMERAL`, `PHRASE`. Articles and possessive/demonstrative adjectives are `DETERMINER`. Use `PHRASE` only for fixed multi-word expressions. |
| `level`        | string                | Always exactly `"C2"`. |
| `gender`       | string or null        | Nouns only: `"masculine"`, `"feminine"`, or `"masculine/feminine"` for nouns that keep the same form for both (e.g. "estudiante"). `null` for every other part of speech. |
| `rank`         | integer               | The rank from step 1 (for a merged lemma, the lowest rank of the input words merged into it). |
| `tags`         | array of strings      | 1 to 3 tags from the allowed list, most relevant first. Use `common` for core everyday words, and `grammar` for function words (articles, pronouns, prepositions, conjunctions, auxiliary verbs). |
| `sentences`    | array of 2 objects    | Each object is `{ "sentence": string, "translation": string }`. See the rules below. |

### Rules for sentences

- Write exactly 2 sentences, each showing a different, common use of the word.
- Each sentence must contain the word (any inflected form is fine, e.g. "tengo" for "tener").
- Keep them level-appropriate: at A1/A2, 4–10 words using only simple, frequent vocabulary and the present tense
  where possible; at C2 and above, up to 16 words, with more varied grammar.
- Write natural, correct Spanish, including accents and inverted punctuation (¿...?, ¡...!).
- `translation` is a natural, accurate English translation of the whole sentence.
- Don't use real people's names; use common first names or pronouns.
